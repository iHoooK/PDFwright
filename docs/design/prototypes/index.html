Три направления для PDFwright

Каждый прототип кликабельный: вкладки, инструменты, масштаб, режим «Страницы», боковые панели, настройки и тема. Содержимое страниц условное. Откройте любой в отдельной вкладке, чтобы посмотреть в полный размер.

Вариант A

«Кабинет»

Светлая тёплая бумага и спокойная читальня. Панели — мягкие карточки на тёплом сером фоне, вкладки‑«пилюли», узкая рейка с панелями слева, свойства справа. Акцент — чернильный синий только для действия и выбора.

  • Самый спокойный вариант для долгого чтения.
  • Подписи у инструментов, крупные зоны клика.
  • Тёмная тема — тёплая, без холодного синего.

Вариант B

«Студия»

Тёмная профессиональная мастерская в духе графических редакторов. Плавающая палитра инструментов внизу с горячими клавишами, инспектор с вкладками справа, точечная сетка холста, плотная компоновка. Акцент — янтарный.

  • Максимум места документу, минимум отвлекающего.
  • Инспектор: свойства, список аннотаций, документ.
  • Светлая тема — холодная серая, как у Figma.

Вариант C

«Лента»

Родной Windows 11 Fluent: слоистый фон, командная панель с подписями под иконками как в Проводнике, вкладки‑«карточки», боковая панель с текстовыми вкладками, настройки в стиле «Параметров» Windows. Акцент — системный синий.

  • Мгновенно знакомо пользователям Windows.
  • Каждая команда подписана, не нужно запоминать иконки.
  • Тёмная тема повторяет тёмный режим Windows 11.
