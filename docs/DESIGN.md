# PDFwright — дизайн-система

Направление: **«Лента»** (выбрано автором 2026-10-24 из трёх прототипов, см. `docs/design/prototypes/`). Родной для Windows 11 Fluent-стиль: слоистый фон, командная панель с подписями под иконками как в Проводнике, вкладки-карточки, боковая панель с текстовыми вкладками, настройки в стиле «Параметров» Windows. Документ — единственный насыщенный объект на экране; интерфейс нейтральный и предсказуемый.

Регистр: продуктовый. Знакомость — достоинство. Акцент только для действия, выбора и текущего состояния. Никакой декоративной анимации.

Эталон живого вида — `docs/design/prototypes/c-lenta.html`. При расхождении этого документа и прототипа приоритет у этого документа.

## 1. Цвет

Токены задаются на `:root`, тёмная тема переопределяет их через `[data-theme="dark"]`; значение `system` приложения выбирает тему по `prefers-color-scheme`.

| Токен           | Светлая                                   | Тёмная                                    | Назначение                                                                 |
| --------------- | ----------------------------------------- | ----------------------------------------- | -------------------------------------------------------------------------- |
| `--mica`        | `linear-gradient(180deg,#f1f3f8,#edf0f5)` | `linear-gradient(180deg,#202020,#1c1c1c)` | Фон окна за вкладками                                                      |
| `--bg`          | `#f3f3f3`                                 | `#202020`                                 | Холст вокруг страниц, фон сетки страниц                                    |
| `--layer`       | `rgba(255,255,255,.7)`                    | `rgba(255,255,255,.055)`                  | Hover-слой, выбранная строка                                               |
| `--layer-solid` | `#fbfbfb`                                 | `#2b2b2b`                                 | Панели: командная, боковая, свойства, строка состояния                     |
| `--card`        | `#ffffff`                                 | `#2b2b2b`                                 | Карточки настроек, поля ввода, плитки                                      |
| `--paper`       | `#ffffff`                                 | `#ffffff`                                 | Страница PDF (в тёмной теме остаётся белой)                                |
| `--ink`         | `#1b1b1b`                                 | `#ffffff`                                 | Основной текст                                                             |
| `--ink-2`       | `#5d5d5d`                                 | `#c5c5c5`                                 | Второстепенный текст, иконки команд                                        |
| `--ink-3`       | `#8a8a8a`                                 | `#8f8f8f`                                 | Подписи, плейсхолдеры, номера страниц                                      |
| `--line`        | `rgba(0,0,0,.08)`                         | `rgba(255,255,255,.08)`                   | Разделители панелей, границы карточек                                      |
| `--line-2`      | `rgba(0,0,0,.16)`                         | `rgba(255,255,255,.16)`                   | Границы полей ввода, кнопок                                                |
| `--accent`      | `#0067c0`                                 | `#4cc2ff`                                 | Primary-кнопка, выбранный элемент, индикатор вкладки, фокус переключателей |
| `--accent-ink`  | `#ffffff`                                 | `#003a5c`                                 | Текст на акценте                                                           |
| `--accent-soft` | `rgba(0,103,192,.10)`                     | `rgba(76,194,255,.14)`                    | Фон нажатой команды, выбранной миниатюры                                   |
| `--mark`        | `#ffd86b`                                 | `#ffd86b`                                 | Маркер по умолчанию на странице                                            |
| `--danger`      | `#c42b1c`                                 | `#ff99a4`                                 | Ошибки, разрушающие действия                                               |
| `--success`     | `#0f7b0f`                                 | `#6ccb5f`                                 | «Сохранено», успешная проверка                                             |

Правила:

- Акцент не используется на неактивных состояниях и не служит декором.
- Текст на `--layer-solid` и `--card` обязан давать контраст ≥ 4.5:1 (`--ink`, `--ink-2`); `--ink-3` допускается только для вспомогательных подписей ≥ 12 px.
- Страница PDF всегда белая: тёмная тема не инвертирует содержимое документа (инверсия — отдельная P2-функция «ночной режим чтения»).
- Цвета аннотаций (маркер, перо, фигуры) — пользовательская палитра, не токены интерфейса: `#ffd86b #9be39b #9fd3ff #ffb0c8 #d7bfff` плюс чёрный и красный для пера.

## 2. Типографика

Одна семья: `"Segoe UI Variable Text", "Segoe UI", system-ui, sans-serif`. Моноширинный для диагностики: `Cascadia Mono, Consolas, monospace`.

| Роль             | Размер / начертание          | Где                                                        |
| ---------------- | ---------------------------- | ---------------------------------------------------------- |
| Заголовок экрана | 22–24 px / 600               | Стартовый экран, разделы настроек                          |
| Заголовок панели | 14 px / 600                  | «Маркер», «Документ», `h2` боковой панели настроек (20 px) |
| Основной текст   | 14 px / 400, line-height 1.4 | Кнопки, списки, поля                                       |
| Подпись команды  | 11.5 px / 400, line-height 1 | Под иконками командной панели                              |
| Вторичный текст  | 12–13 px / 400               | Пояснения в настройках, метаданные документа               |
| Строка состояния | 12 px / 400                  | Низ окна                                                   |

Шкала фиксированная в px (DPI у пользователя постоянный), без fluid-типографики. Табличные цифры (`font-variant-numeric: tabular-nums`) для процента масштаба, номеров страниц, размеров.

Русская типографика: неразрывный пробел после коротких предлогов и союзов (`в&nbsp;один`, `и&nbsp;настройки`), кавычки «ёлочки», тире «—» с пробелами, точка в сокращениях («стр.», «окт.»).

## 3. Сетка и размеры

| Область                    | Размер    | Примечание                                               |
| -------------------------- | --------- | -------------------------------------------------------- |
| Заголовок окна с вкладками | 46 px     | Фон `--mica`; вкладки-карточки 8 px скругление сверху    |
| Командная панель           | 60 px     | Команды 56 px min-width, иконка 20 px + подпись          |
| Боковая панель             | 236 px    | Вкладки «Страницы · Закладки · Поиск»; сворачивается в 0 |
| Панель свойств             | 252 px    | Карточки `--card`; сворачивается в 0                     |
| Строка состояния           | 26 px     | Страница, формат, подсказка клавиш, статус сохранения    |
| Минимальное окно           | 900 × 600 | При ширине < 1100 панель свойств скрыта по умолчанию     |

Отступы: шкала 4 px (4, 8, 12, 16, 24, 32, 40). Внутри карточек 14–18 px. Между страницами на холсте 20 px, поля холста 24 px сверху.

Скругления: `--r: 8px` (карточки, плитки, вкладки, панели), `--r-s: 4px` (кнопки, поля, команды, миниатюры). Страница PDF — 2 px.

Тени: `--shadow` для всплывающих слоёв (меню, тосты), `--page-shadow` только для страниц. Панели теней не имеют, их разделяют линии `--line`.

## 4. Компоненты и состояния

У каждого интерактивного элемента есть default, hover, focus-visible, active/pressed, disabled; у действий с ожиданием — loading; у полей — error.

- **Команда (`.cmd`)**: иконка 20 px над подписью 11.5 px; hover `--layer`; pressed `--accent-soft` + акцентная иконка (stroke 1.8); disabled — opacity .45, без hover.
- **Кнопка (`.btn`)**: 32 px высота, фон `--card`, граница `--line-2`, нижняя граница `--ink-3` (Fluent); primary — заливка `--accent`.
- **Переключатель (toggle)**: 40 × 20 px, подпись «Вкл./Выкл.» слева, включённый — `--accent`.
- **Выпадающий выбор (select)**: 32 px, шеврон справа, min-width 160 px.
- **Радиокнопка**: 18 px круг, выбранная — кольцо 5 px `--accent`.
- **Вкладка документа**: карточка на `--mica`; активная — `--layer-solid` с линией по краям; крестик появляется на hover и у активной.
- **Вкладка панели**: текстовая, активная — подчёркивание 3 px `--accent`, жирность 600.
- **Миниатюра страницы**: белая, тень 1 px; текущая — рамка 2 px `--accent` и фон `--accent-soft`; в режиме «Страницы» чекбокс в углу.
- **Карточка настроек (`.scard`)**: иконка 18 px слева, заголовок 500, пояснение `--ink-3`, контрол справа.
- **Тост**: `--card`, акцентная полоска слева, 1.6 с, низ по центру.
- **Поле поиска**: нижняя граница `--ink-3`, в фокусе 2 px `--accent`.

Фокус с клавиатуры: `outline: 2px solid var(--ink); outline-offset: 1px` (контрастное кольцо, не акцент). Порядок Tab: вкладки → командная панель → боковая панель → холст → свойства.

Пустые состояния объясняют, чего нет, и дают первое действие («Нет недавних файлов. Откройте PDF или перетащите его в окно»). Загрузка документа — скелет страниц нужного размера, не спиннер посреди холста.

## 5. Иконки

Линейные, stroke 1.5 (1.8 в активном состоянии), скруглённые концы, сетка 24, размеры 18 px в панелях и 20 px в командной панели. Набор в прототипе — временный; в реализации используется один набор (Fluent UI System Icons, MIT) для единого стиля с Windows 11. Смешивать наборы нельзя.

## 6. Движение

150–200 мс, `ease-out`; только для смены состояния (hover-фон, переключатель, тост, сворачивание панелей). Без анимации появления экранов и страниц. При `prefers-reduced-motion` переходы отключаются.

## 7. Экраны

- **Стартовый**: заголовок, крупная primary-плитка «Открыть PDF» (2 колонки) + три плитки инструментов, ниже список «Недавние» (миниатюра, имя, папка, страницы, дата, шеврон).
- **Просмотр**: командная панель; слева «Страницы / Закладки / Поиск»; холст с непрерывной прокруткой; справа свойства текущего инструмента и карточка «Документ».
- **Режим «Страницы»**: вместо холста сетка миниатюр 140 px с мультивыбором; над ней строка действий «Повернуть · Извлечь · Вставить · Удалить» и счётчик выбранных.
- **Параметры**: навигация слева (Общие, Просмотр, Обновления, О программе, О разработчике, «Назад к документу» внизу), справа карточки `.scard`.

## 8. Что взято из других вариантов

- Горячие клавиши инструментов из B (V, H, M, P, U, T, S) показываются в подсказках команд.
- Список аннотаций страницы из инспектора B появится вкладкой панели свойств в фазе 4.

## 9. Логотип и иконка

Знак: буква «P» белым на скруглённом квадрате цвета `--accent` (`#0067c0`), радиус 22 % стороны. Для `.ico` 16–256 px и `.png` 512 px рисуется в `resources/icon.svg` в фазе 1 (пункт 1.1.1) и утверждается автором.
