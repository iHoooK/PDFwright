# Снимки PDFwright для сайта

Снимки 2880×1800 (окно 1440×900, масштаб 2) — чёткие и на экранах с высокой плотностью. Для сайта их можно уменьшить до 1440 или 1200 по ширине. На снимках только демо-документы: вымышленный отчёт студии «Северный ветер» и демо-договор.

Пересобрать снимки после изменений в программе:

```bash
npm run build && npm run site:shots
```
