## Для Mac

PDFwright для macOS 13 Ventura и новее — та же программа, что и для Windows. Какой у Mac процессор, видно в меню Apple → «Об этом Mac»: строка «Чип» с Apple M1, M2 и новее — Apple Silicon, строка «Процессор» с Intel — Intel.

| Файл                                      | Назначение                                                           |
| ----------------------------------------- | -------------------------------------------------------------------- |
| `PDFwright-Mac-AppleSilicon.dmg`          | Установка на Mac с Apple Silicon: перетащите PDFwright в «Программы» |
| `PDFwright-Mac-Intel.dmg`                 | Установка на Mac с Intel                                             |
| `PDFwright-Portable-Mac-AppleSilicon.zip` | Переносная версия для Apple Silicon: распакуйте и запускайте         |
| `PDFwright-Portable-Mac-Intel.zip`        | Переносная версия для Intel                                          |
| `SHA256SUMS-Mac.txt`                      | Контрольные суммы Mac-файлов                                         |

Программа не подписана Apple, поэтому первый запуск нужно разрешить один раз. macOS 15 и новее: откройте PDFwright, закройте предупреждение, затем **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть**. macOS 13–14: правый щелчок по PDFwright в «Программах» → **Открыть** → **Открыть**. Подробнее, а также про обновление и удаление — в [README](https://github.com/iHoooK/PDFwright#для-mac).
