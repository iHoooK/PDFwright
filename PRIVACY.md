# Приватность — PDFwright

PDFwright работает локально.

- Приложение не создаёт аккаунты.
- Приложение не содержит телеметрии и рекламы.
- Открытые документы, их содержимое, введённый текст, подписи и буфер обмена не отправляются разработчику или третьим лицам.
- Файлы сохраняются туда, куда укажет пользователь. Если это OneDrive, сетевая папка или папка другой синхронизации, её провайдер может передавать файлы независимо от PDFwright.
- Список недавних файлов — локальный перечень путей (с временем открытия и числом страниц), а не копия документов. Файл попадает в него, когда открыт во вкладке или сохранён программой; файлы, выбранные только как источник для «Объединить», «Разделить» и других инструментов, туда не добавляются.
- Приложение обращается к GitHub только за обновлениями. Проверка запрашивает `latest.yml` последнего опубликованного релиза `iHoooK/PDFwright`: автоматически через 10 секунд после запуска и раз в 12 часов, пока программа открыта, а также по кнопке «Проверить обновления». Автоматическую проверку можно выключить: **Параметры → Обновления → Проверять обновления автоматически**. Установщик скачивается только после нажатия «Обновить» или «Скачать и установить». GitHub и его серверы скачивания получают обычные данные HTTP-соединения, включая IP-адрес и User-Agent с версией приложения; документы, настройки, недавние файлы и буфер обмена в этих запросах не передаются.
- Скачанный установщик проверяется по sha512 из метаданных релиза и хранится в `%LocalAppData%\pdfwright-updater`. Незавершённые и отклонённые загрузки удаляются; после установки файл можно удалить вручную.
- Кнопки страницы релизов, сайта и каналов автора по явной команде открывают внешний браузер. Разрешены только заранее перечисленные адреса; ссылки из самих PDF-документов приложение не открывает.

Служебные данные (настройки, недавние файлы) хранятся в `%APPDATA%\PDFwright`, скачанные установщики — в `%LocalAppData%\pdfwright-updater`:

```text
%APPDATA%\PDFwright
%LocalAppData%\pdfwright-updater
```

На Mac служебные данные хранятся в `~/Library/Application Support/PDFwright`; проверка обновлений запрашивает там `latest-mac.yml`, а установщики программа не скачивает.

Удалить их можно, закрыв приложение и удалив эту папку. Деинсталлятор пользовательские документы не трогает.

При самостоятельной сборке команда `npm ci` скачивает открытые зависимости из npm. После этого приложение запускается локально; `npm run dev` не отправляет документы или настройки в сеть.
